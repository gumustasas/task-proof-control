# T-011 — Gemini repository secret ile metadata erişimi

Durum: kod hazır; canlı workflow henüz çalıştırılmadı. Bağımlılık: kullanıcının GEMINI_API_KEY eklediğini bildirmesi. Ücretli üretim kapsamında değildir.

Plan koddan önce research/seo-comparison/gemini-access-plan.md'ye yazıldı. Sabit model için tek GET, header-only key, redirect reddi, timeout/body sınırı ve sınırlı log eklendi. Tek adımlık secret env yalnız main workflow_dispatch içinde kullanılır. Normal PR testlerinde secret/ağ yok.

Kabul: secret hata gövdesinde/URL'de/logda görünmez; model üretimi/retry/fallback yok; metadata sonucu Free Tier/kota veya A/B başarısı diye sunulmaz. Altı yeni test bu sınırları ve hata durumlarını doğrular. Yerelde 55/55 test, sıfır skip/failure. Exact-head CI PR'da kaydedilir.

Canlı kontrol engeli: GitHub bağlantısı workflow dispatch sunmuyor, yerel gh auth doğrulanmadı. PR/CI/squash sonrası kullanıcı [workflow](https://github.com/gumustasas/task-proof-control/actions/workflows/gemini-access.yml) sayfasında main seçerek bir kez Run workflow yapmalı. Sonraki asistan bu koşunun metadata işini ve tam commit'ini kontrol eder. Anahtar değeri alınmaz.

T-010 A/B açık kalır. Üretim denemesinden önce AI Studio Free Tier/kota ve aynı istemde baseline ayrıca hazırlanmalı.
